Podés agregar/sacar imágenes en index.html (bloque .manifesto__reveal-layer).
Cada una tiene estilos inline --pos-x / --pos-y (posición en % dentro de la
sección) y --pos-w (ancho en px) para ubicarlas donde quieras.

Recomendación: imágenes en formato 4:5 (vertical), recortadas/optimizadas
para web (jpg o webp, idealmente < 300kb cada una).
